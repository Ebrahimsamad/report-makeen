# THC IT Monthly Reports Dashboard

نظام إدارة الأداء الشهري — إدارة تقنية المعلومات

## الميزات

- 📊 لوحة تحكم تفاعلية بالعربي (RTL)
- 🌙 Dark/Light mode
- 📄 تصدير PDF احترافي
- 🔍 بحث وفلترة في المؤشرات
- 📱 Responsive design

## الرفع على Vercel

### طريقة 1: Vercel CLI

```bash
npm i -g vercel
vercel --prod
```

### طريقة 2: Drag & Drop

1. افتح vercel.com
2. اسحب مجلد المشروع كاملاً
3. انتظر النشر

### طريقة 3: GitHub

1. ارفع المجلد على GitHub repo
2. اربطه بـ Vercel من vercel.com/new

## الملفات

- `index.html` — الصفحة الرئيسية
